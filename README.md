# Mauro's Value

Fan-made market values for every player at Galatasaray, Fenerbahçe, Beşiktaş and Trabzonspor, in Turkish and English.

**Live site:** https://ruzgarkonuksever.github.io/mauros-value/

- Market values are our own estimates, not Transfermarkt's.
- Season stats (games, goals, assists, yellow and red cards) come from GOAL API match data and are updated every week.
- Player photos come from Wikimedia Commons under free licences; each player's popup credits the photographer.

Not affiliated with any club or with Transfermarkt.
